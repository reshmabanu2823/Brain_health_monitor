# CORTIA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Functional local brain monitoring workstation with honest acquisition and separate MRI inference.
**Architecture:** Fresh Python modules for hardware, processing, analytics, storage and APIs. React client consumes verified server output. SQLite stores provenance, private files store raw recordings and images.
**Tech Stack:** FastAPI, SQLAlchemy, NumPy/SciPy, scikit-learn, Argon2, pyserial, React, TypeScript, Vite, Tailwind, Recharts.
**Spec:** docs/superpowers/specs/2026-11-01-cortia-design.md

## Global Constraints
No fabricated production samples, baselines or dashboard values. No diagnostic EEG claims. No gamma. Physical hardware integration remains unverified until tested. Actual MRI inference must be tested. Separate measured/calculated/model/explanation data.

## Review Focus
Counter wrap and serial corruption must not silently create continuous data.
User B must never read user A’s session, stream, image or report.
Repeated windows from one session must not count as independent baseline sessions.
Uploads must remain bounded and predictions must match original artifact preprocessing.
Disconnected devices and application restart must finalize interrupted recordings honestly.
